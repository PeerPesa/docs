title: "List asset balances and wallet addresses per network"

The asset balances endpoint lists every coin your PeerPesa account holds, such as USDC, together with the wallet addresses PeerPesa generated for it on each blockchain network and the balance held at each address. One coin can have several addresses, for example a Stellar address with a memo, a Solana address, and EVM (`0x`) addresses, because each network keeps its own balance.

## GET /wallet/assets

Returns all assets for the authenticated account, one entry per coin.

<CodeGroup>

```bash cURL
curl https://api.peerpesa.co/v2/wallet/assets \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

```javascript JavaScript
const res = await fetch("https://api.peerpesa.co/v2/wallet/assets", {
  headers: { Authorization: `Bearer ${accessToken}` },
});
const { data: assets } = await res.json();
```

</CodeGroup>

<Note>
  `balance` is returned as a number, not a decimal string. To get the total held for a coin, add up `balance` across every entry in `addressCollections`. In the example, the USDC total is `0.003442`.
</Note>

<Warning>
  When a wallet has a `memo`, include it with every deposit to that address. Deposits to shared Stellar or Solana addresses without the correct memo cannot be credited to your account.
</Warning>

## Asset fields

<ResponseField name="id" type="string">
  Coin ID (UUID). Matches `coin_id` on each wallet.
</ResponseField>

<ResponseField name="token_name" type="string">
  Display name of the coin, for example `USDC`.
</ResponseField>

<ResponseField name="symbol" type="string">
  Ticker symbol, for example `USDC`.
</ResponseField>

<ResponseField name="label" type="string">
  Optional display label. Empty when not set.
</ResponseField>

<ResponseField name="contract_address" type="string | null">
  Token contract address, when the coin has a single contract. `null` for coins issued on several networks, where each network has its own contract.
</ResponseField>

<ResponseField name="blockchain" type="string">
  Blockchain name for single-network coins. Empty for multi-network coins such as USDC.
</ResponseField>

<ResponseField name="total_supply" type="string">
  Token supply as a decimal string. Informational only.
</ResponseField>

<ResponseField name="decimals" type="integer">
  Token decimal places, where set.
</ResponseField>

<ResponseField name="token_type" type="string">
  Token type, for example `Native`.
</ResponseField>

<ResponseField name="status" type="string">
  `active` or `inactive`. Inactive coins cannot be deposited, sent, or swapped.
</ResponseField>

<ResponseField name="icon" type="string">
  URL of the coin icon for display in your UI.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp when the coin was added.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the last change to the coin.
</ResponseField>

<ResponseField name="deleted_at" type="string | null">
  Set when the coin has been removed. `null` for available coins.
</ResponseField>

<ResponseField name="wallet" type="object">
  The primary wallet for this coin. Same shape as an entry in `addressCollections`.
</ResponseField>

<ResponseField name="addressCollections" type="object[]">
  Every wallet address you hold for this coin, one or more per network.

  <Expandable title="wallet properties">
    <ResponseField name="id" type="string">
      Wallet ID (UUID).
    </ResponseField>

    <ResponseField name="user_id" type="string">
      ID of the account that owns the wallet.
    </ResponseField>

    <ResponseField name="label" type="string">
      Wallet label, for example `USDC Wallet`.
    </ResponseField>

    <ResponseField name="memo" type="string">
      Memo or destination tag to include with deposits. Empty when the address is not shared, such as `0x` addresses.
    </ResponseField>

    <ResponseField name="address" type="string">
      Deposit address on the wallet's network.
    </ResponseField>

    <ResponseField name="details" type="string">
      Extra wallet details. Usually empty.
    </ResponseField>

    <ResponseField name="wallet_key" type="string">
      Reserved. Always returned empty.
    </ResponseField>

    <ResponseField name="coin_id" type="string">
      ID of the coin this wallet holds.
    </ResponseField>

    <ResponseField name="blockchain_network_id" type="string">
      ID of the blockchain network the address belongs to.
    </ResponseField>

    <ResponseField name="account_type" type="string">
      Owner type, for example `user`.
    </ResponseField>

    <ResponseField name="status" type="string">
      `active` or `inactive`.
    </ResponseField>

    <ResponseField name="is_default" type="integer">
      `1` if this is the default wallet for the coin, otherwise `0`.
    </ResponseField>

    <ResponseField name="balance" type="number">
      Balance held at this address, in whole coin units.
    </ResponseField>

    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp when the address was generated.
    </ResponseField>

    <ResponseField name="updated_at" type="string | null">
      ISO 8601 timestamp of the last update, or `null`.
    </ResponseField>

    <ResponseField name="deleted_at" type="string | null">
      Set when the wallet has been removed.
    </ResponseField>
  </Expandable>
</ResponseField>

## Reading balances in your app

```javascript Total balance per coin
const res = await fetch("https://api.peerpesa.co/v2/wallet/assets", {
  headers: { Authorization: `Bearer ${accessToken}` },
});
const { data: assets } = await res.json();

const balances = assets
  .filter((asset) => asset.status === "active")
  .map((asset) => ({
    symbol: asset.symbol,
    icon: asset.icon,
    total: asset.addressCollections.reduce((sum, w) => sum + w.balance, 0),
    addresses: asset.addressCollections.map((w) => ({
      network_id: w.blockchain_network_id,
      address: w.address,
      memo: w.memo || null,
      balance: w.balance,
    })),
  }));
```
