A beneficiary is a saved recipient you can pay again without re-entering their details. PeerPesa supports three beneficiary types: `bank_account` and `phone_number` (mobile money) for fiat payouts through [offramps](/api-reference/offramp) and [withdrawals](/api-reference/withdraw), and `wallet_address` for crypto [sends](/api-reference/send). Create a beneficiary once, then reference its `id` as `beneficiary_id`.

## Beneficiary types

| Type | Use for | Required details |
| --- | --- | --- |
| `bank_account` | Fiat payouts to a bank account | `bank_code`, `account_number`, `account_name` |
| `phone_number` | Fiat payouts to a mobile money wallet | `phone_number`, `provider` |
| `wallet_address` | Crypto sends to a Stellar, Celo, or Bitcoin wallet | `wallet_address`, `network`, `asset`, optional `memo` |

## The beneficiary object

<ResponseField name="id" type="string">
  Unique identifier, for example `ben_3m7q2c`.
</ResponseField>

<ResponseField name="type" type="string">
  `bank_account`, `phone_number`, or `wallet_address`.
</ResponseField>

<ResponseField name="name" type="string">
  Recipient's full name or a label for the wallet.
</ResponseField>

<ResponseField name="country" type="string | null">
  ISO 3166-1 alpha-2 country code, for example `KE`. `null` for `wallet_address`.
</ResponseField>

<ResponseField name="currency" type="string | null">
  Payout currency: `KES`, `TZS`, `NGN`, `ZAR`, or `ZMW`. `null` for `wallet_address`.
</ResponseField>

<ResponseField name="details" type="object">
  Recipient details for the beneficiary `type`.

  <Expandable title="properties">
    <ResponseField name="bank_code" type="string">
      `bank_account` only. Recipient bank's code.
    </ResponseField>

    <ResponseField name="bank_name" type="string">
      `bank_account` only. Bank name resolved from `bank_code`.
    </ResponseField>

    <ResponseField name="account_number" type="string">
      `bank_account` only. Recipient's account number.
    </ResponseField>

    <ResponseField name="account_name" type="string">
      `bank_account` only. Name on the bank account.
    </ResponseField>

    <ResponseField name="phone_number" type="string">
      `phone_number` only. Phone number in international format.
    </ResponseField>

    <ResponseField name="provider" type="string">
      `phone_number` only. Mobile money provider, for example `mpesa`.
    </ResponseField>

    <ResponseField name="wallet_address" type="string">
      `wallet_address` only. Destination wallet address.
    </ResponseField>

    <ResponseField name="network" type="string">
      `wallet_address` only. Network of the address: `stellar`, `celo`, or `btc`.
    </ResponseField>

    <ResponseField name="asset" type="string">
      `wallet_address` only. Asset to send, for example `USDC`, `XLM`, `cUSD`, or `USDT`.
    </ResponseField>

    <ResponseField name="memo" type="string">
      `wallet_address` only. Memo for Stellar destinations such as exchanges. Empty when not needed.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 creation timestamp.
</ResponseField>

## POST /beneficiaries

Creates a beneficiary.

<ParamField body="type" type="string" required>
  `bank_account`, `phone_number`, or `wallet_address`.
</ParamField>

<ParamField body="name" type="string" required>
  Recipient's full name, or a label for a wallet.
</ParamField>

<ParamField body="country" type="string">
  ISO 3166-1 alpha-2 country code. Required for `bank_account` and `phone_number`.
</ParamField>

<ParamField body="currency" type="string">
  Payout currency. Required for `bank_account` and `phone_number`, and must be supported for the country.
</ParamField>

<ParamField body="bank_account" type="object">
  Required when `type` is `bank_account`.

  <Expandable title="properties">
    <ParamField body="bank_code" type="string" required>
      Recipient bank's code.
    </ParamField>

    <ParamField body="account_number" type="string" required>
      Recipient's account number.
    </ParamField>

    <ParamField body="account_name" type="string" required>
      Name on the bank account.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="phone_number" type="object">
  Required when `type` is `phone_number`.

  <Expandable title="properties">
    <ParamField body="phone_number" type="string" required>
      Phone number in international format, for example `+254712345678`.
    </ParamField>

    <ParamField body="provider" type="string" required>
      Mobile money provider, for example `mpesa`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="wallet_address" type="object">
  Required when `type` is `wallet_address`.

  <Expandable title="properties">
    <ParamField body="wallet_address" type="string" required>
      Destination wallet address. Validated against the `network` format.
    </ParamField>

    <ParamField body="network" type="string" required>
      `stellar`, `celo`, or `btc`.
    </ParamField>

    <ParamField body="asset" type="string" required>
      Asset to send on that network. See [Currencies](/api-reference/coins).
    </ParamField>

    <ParamField body="memo" type="string">
      Memo for Stellar addresses that require one, such as exchange deposit addresses.
    </ParamField>
  </Expandable>
</ParamField>

## GET /beneficiaries

Lists beneficiaries, newest first. Supports all [pagination and filter parameters](/pagination).

<ParamField query="page" default="1" type="integer">
  Page number to return, starting at `1`.
</ParamField>

<ParamField query="size" default="20" type="integer">
  Results per page, up to `100`. `limit` is accepted as an alias.
</ParamField>

<ParamField query="type" type="string">
  Filter by beneficiary type: `bank_account`, `phone_number`, or `wallet_address`. Comma-separate to match several.
</ParamField>

<ParamField query="search" type="string">
  Matches name, phone number, account number, bank name, and wallet address. Minimum 2 characters.
</ParamField>

<ParamField query="start_date" type="string">
  Only include beneficiaries created on or after this date (`YYYY-MM-DD` or ISO 8601).
</ParamField>

<ParamField query="end_date" type="string">
  Only include beneficiaries created on or before this date (`YYYY-MM-DD` or ISO 8601).
</ParamField>

<ParamField query="country" type="string">
  Filter by ISO country code, for example `KE`.
</ParamField>

<ParamField query="currency" type="string">
  Filter by payout currency, for example `KES`.
</ParamField>

<ParamField query="network" type="string">
  Filter `wallet_address` beneficiaries by network: `stellar`, `celo`, or `btc`.
</ParamField>

<ParamField query="sort_by" default="created_at" type="string">
  `created_at` or `name`.
</ParamField>

<ParamField query="sort_order" default="desc" type="string">
  `desc` or `asc`.
</ParamField>

<CodeGroup>

```bash cURL
curl "https://api.peerpesa.co/v2/beneficiaries?page=1&size=20&type=phone_number&country=KE" \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

## GET /beneficiaries/\{id\}

Retrieves one beneficiary. Returns `404` with code `not_found` if the ID does not exist.

```bash cURL
curl https://api.peerpesa.co/v2/beneficiaries/ben_3m7q2c \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

## DELETE /beneficiaries/\{id\}

Deletes a beneficiary. Returns `204 No Content` on success. Past transactions to this beneficiary are not affected.

```bash cURL
curl -X DELETE https://api.peerpesa.co/v2/beneficiaries/ben_3m7q2c \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

## Errors

| Code | Status | Cause |
| --- | --- | --- |
| `missing_parameter` | 400 | The details object for the `type` is missing, for example `bank_account` when `type` is `bank_account`. |
| `invalid_parameter` | 400 | Unknown `type` or an invalid account number. `param` names the field. |
| `invalid_phone_number` | 422 | Phone number format is invalid for the country. |
| `invalid_wallet_address` | 422 | `wallet_address` is not valid for the `network`. |
| `unsupported_pair` | 422 | `currency` or `provider` is not supported for the `country`. |
| `unsupported_asset` | 422 | `asset` is not available on the chosen `network`. |
| `not_found` | 404 | No beneficiary with this ID. |
